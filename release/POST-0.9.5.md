## 0.9.5

**vernon stops asking you to do a job you already did** — the offer was reading the
same flag the basement door is locked behind, and the settings switch that locks the
door takes that flag off. so locking the basement un-completed the mission. he only
pitches now if you've never taken it, or the last go ended in death, arrest, or him
getting killed.

**ardo and vernon stop talking over each other** — the talking face is a loop and the
last one to speak was never shut up, so both mouths moved at once.

**vernon stops getting stuck in the scrapyard** — nothing took the combat task off him
when the last armenian went down, so he stood there fighting nobody and couldn't be
told to follow.

**failing a job no longer starts lamar's ten minute wait.** that was never meant to
happen.

**and the build can't lie about a release any more** — on 0.9.4 one of the two
downloads failed to upload and the script said "published, both attached" anyway,
because nothing checked. it retries now and then asks the release page what's actually
on it.
